# 🧮 Task 3: Calculator App

A modern, responsive, and crash-proof Android Calculator application built using Java and XML as part of the **Oasis Infobyte Android Development Internship**.

---

## 📱 Features
* 🔢 **Full Numpad:** Buttons from `0` to `9` and decimal point (`.`).
* ➕ **Basic Operations:** Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`).
* ⌫ **Backspace Button:** Easily delete the last entered digit without clearing the whole screen.
* 🧹 **Clear (C) Button:** Instantly reset the display.
* ⚠️ **Error Handling:** Division-by-zero protection displaying `"Error"` instead of crashing.
* 📱 **Grid Layout:** Clean 5x4 button grid layout optimized for responsive screen fits.

---

## 🛠️ Tech Stack & Architecture
* **Language:** Java
* **UI Layout:** XML (`GridLayout` & `TextView`)
* **Target SDK:** 34 | **Min SDK:** 21
* **Build Automation:** GitHub Actions CI/CD (Gradle 8.4)
